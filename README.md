# Arobi Amin — Software QA Engineer

> A cinematic, responsive portfolio showcasing 3+ years of expertise in software quality assurance, manual & functional testing, and enterprise system reliability.

---

## ✨ Highlights

- **🌸 Cinematic Cherry Blossom Effects:** Dynamic wind-reactive petal rain, subtle puddle blooms, and alternating rose & sapphire themes.
- **🧪 Enterprise QA Showcase:** Comprehensive test documentation and validation breakdown for SkyChat, SkyVat, and university ERP systems.
- **🧭 Adaptive Floating Navigation:** Top header that smoothly transitions into an active-tracking floating vertical dock as you scroll.
- **📸 Milestone Gallery:** Interactive 9-photo chronicle featuring university achievements, lab research, and professional SQA engineering at Codezzi.
- **📄 Instant CV Access:** Built-in resume download and verified contact channels.

---

## 🛠 Tech Stack

- **Framework:** React 19, Vite, TanStack Router
- **Styling:** Tailwind CSS, PostCSS
- **Animations:** Framer Motion
- **Icons:** Lucide React
- **Language:** TypeScript

---

## 🚀 Getting Started

```bash
# Install dependencies
npm install

# Start local development server
npm run dev

# Build for production
npm run build
```
